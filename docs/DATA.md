returns the closed shared `bbr.contracts.FamilySpec`; `load_spec(path)` reads the
bounded JSON subset of YAML, rejects duplicate keys, and requires the original
definition. `render_spec(spec, codec)` rejects changed/unknown definitions.
`dossier(id)` adds dev-only
provenance and trap notes. `reference(id, values)` is a builder dev reference.
`render(id, codec)` returns original C17 source; it does not invoke a compiler.
Source creation hashes can be computed from the checked-in files and rendered
source after an authorized renderer execution; no unobserved hash is invented.

The first two domains are exactly `{(0,), ... , (255,)}`, so each has 256
canonical inputs by construction. This is a declared capacity argument, not an
executed capacity/admission certificate. Remaining domains have more than 256
inputs. All input values admit the full unsigned range. Exact family arity is
enforced separately from the generic vector codec.

`encode(values, codec, width)` and `decode(raw, codec, width, max_elements=8)`
use bit widths 8 or 16. Dec is comma-separated canonical decimal plus one LF,
with no signs, whitespace, leading zeroes, or trailing bytes. Hex is fixed-width
lowercase digits plus one LF. Bin is one payload-byte-length prefix and little
endian element bytes, with no trailing bytes. Empty vectors are LF for text and
one zero byte for bin. Decoding rejects overflow, more than eight elements, input
over 64 bytes, malformed lengths and unsupported settings with `ValueError`.
Rendered family programs reject malformed/out-of-domain input with empty stdout
and exit 2; valid input produces the matching output codec and exit 0. I/O errors
use exit 3. This source behavior remains unexecuted.

Shared wire API: `bbr.contracts` exports strict/frozen Pydantic v2 models and rejects
unknown fields. `Domain` carries public width/arity/range; `FamilySpec` adds dev-only
lineage. `Observation` distinguishes clean output, subject failure and infrastructure
error. `VisibleTask` contains exactly eight public examples, never family/source fields.
`CandidateResponse` requires code or abstention and caps code at 32 KiB and probes at
eight. `BuildArtifact` pins full ELF, source, toolchain and execution contract hashes.
`Evidence` is a narrow section/string provenance envelope; full retained bytes and
virtual addresses remain in `bbr.evidence.EvidenceBundle`. `Manifest`, `Instance`,
`Counterexample`, `ReplayBundle`, and `Verdict` supply retained-data boundaries.
JSON byte fields serialize as explicit hex. Dependency resolution and runtime wire
round-trips are deferred; compatibility constraints in pyproject are not a lock.

`VisibleTask.probe_inputs` is the complete frozen public pool: exactly 80 unique
raw inputs, with 64 valid under the public codec/domain and 16 malformed. Eight
visible pairs must be unique valid inputs and disjoint from that pool. The model's
chosen `CandidateResponse.probe_inputs` remains capped at eight. Private pools
are never accepted or generated by this model.

`ReplayBundle` retains legacy records without execution context for inspection;
executable replay must call `require_replay_pins()`. Image, argv, environment,
comparator version, move policy and retained trace are supplied together or refused.
The consumer must join those pins to its trusted envelope and isolated runner.
Structural validation does not prove execution or independent custody.

Build API: `bbr.build.build_plan`, `validate_instance` and

Evidence API: `bbr.evidence.extract(artifact_bytes, limits=None)` returns a bounded
bundle with `canonical_json()`, `digest()` and `to_contract()`; no binary execution.
`bbr.screen.screen(text)` returns preserved text, escaped HTML and heuristic flags.
Golden bundle validation and behavior/privacy checks require the later isolated phase.

Public provider evidence uses `bbr.evidence.PublicEvidenceEnvelope`. Construct with
`from_bundle(bundle, expected_artifact_sha256=trusted_artifact_hash)`, or parse canonical
wire bytes using `from_json(raw, expected_artifact_sha256=..., expected_evidence_sha256=...)`.
`validate_for(artifact_sha256=..., evidence_sha256=...)` joins trusted task identity;
`to_dict()` is JSON-safe request content and `canonical_json()` serializes the whole
closed envelope (at most48KiB). The wire has exactly schema_version1, artifact_sha256,
evidence_sha256 and the full bundle. The evidence digest hashes canonical bundle bytes,
matching `EvidenceBundle.digest()` and VisibleTask.evidence_sha256; it does not hash
the outer envelope. Section bytes, addresses, provenance and imports are never dropped.

The parser rejects duplicate/unknown fields, noncanonical JSON, wrong digests/types,
oversized or overlapping sections/strings, unsafe section/symbol labels, inconsistent
screen/escaping annotations and missing truncation disclosures. Only existing extractor
public fields are allowed. Raw evidence strings and bytes remain untrusted: structural
checks cannot establish absence of source semantics, hidden inputs or canaries. Actual
ELF authenticity requires the trusted artifact/evidence commitments. Verified tokenizer
and independent pre-dispatch leak clearance are unavailable, so `require_live_dispatch()`
always refuses. No live release/clearance approval is invented; mock identity may bind
the full envelope while runtime validation remains deferred.
The public profile recognizes printable runs of at least four retained bytes. Custom
extractor profiles that omit such runs without a truncation disclosure are rejected;
the envelope never upgrades omitted evidence into an untruncated claim.

Generic input policy source lives only in `bbr.corpus.input_plan`. Its pure API is
`plan_inputs(domain: Domain, *, seed: bytes, reserved_private=()) -> InputPlan` and
`encode_plan(plan, codec, *, seed) -> EncodedInputPlan`. It requires32 caller seed
bytes, exact public Domain (no FamilySpec/source fields), width8/16, arity1..8 and
at most1024 distinct caller-owned private boundaries. Finite capacity exactly256
uses8 visible/64 public/184 private, with reserved boundaries kept private. Ordinary
capacity must be at least328+B and yields8/64/(256+B), where B is reserved boundaries.
Other capacities fail; population sizes never silently shrink.

Ordinary private recipes contain128 stratified valid rank draws and128 independent
labelled width-shaped little-endian byte draws mapped into the public range. After
deduplication/excluding reserved boundaries, seeded cyclic top-up fills256 distinct
nonreserved private values. A separate bounded pool supplies visible/public values
outside private. The existing `deterministic_partition` orders/selects these pools;
no competing partition algorithm was added. Top-up attempts are bounded by target
plus excluded count; large domains are never exhaustively enumerated. SHA256 counter
labels/version and modulo mapping are fixed; no IID/unbiased sampling claim is made.

`InputPlan.commitment()` pins complete recipe/domain/seed commitment and canonical
pools; `summary()` returns hashes/counts/limitations without raw seeds or private
values. All three codecs inherit the same canonical partitions. `encode_plan` checks
the supplied seed/recipe, creates codec-specific16 public/32 private malformed byte
inputs in at most288 attempts, checks actual invalidity with codec+Domain, and calls
the existing `audit_partitions` for raw/decoded uniqueness/disjointness and finite
coverage. Its `partitions` are existing InputPartition objects; `public_inputs` exposes
only64 valid+16 malformed probe inputs. Never pass a complete private-bearing plan
to model/provider. Byte pools are task/codec-scoped; canonical valid pools are shared.
